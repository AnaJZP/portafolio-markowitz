Calibración de τ y forma alternativa del modelo Black-Litterman

La fórmula de BL tiene dos formas algebraicamente idénticas. La alternativa (derivada con el lema de Woodbury) es mucho más interpretable: es exactamente un filtro de Kalman. El posterior es el prior más una corrección proporcional a la sorpresa de las views.

Forma estándar — Black & Litterman 1990
μ_BL = [(τΣ)⁻¹ + PᵀΩ⁻¹P]⁻¹
× [(τΣ)⁻¹Π + PᵀΩ⁻¹q]
Forma alternativa — Woodbury identity
μ_BL = Π + K · (q − PΠ)

K = τΣPᵀ [PτΣPᵀ + Ω]⁻¹
↑ "Kalman gain" — matriz n×k
Π — punto de partida
El equilibrio de mercado. Sin views (q = PΠ), el posterior es exactamente Π. No hay ajuste.
(q − PΠ) — la sorpresa
Cuánto se desvía tu view del retorno implícito del mercado. Si q coincide con el equilibrio, no hay efecto.
K — la ganancia de Kalman
Qué fracción de la sorpresa se transmite al portafolio. K grande → views dominan. K = 0 → prior inalterado.

Con He-Litterman (Ω = τPΣPᵀ), la ganancia K = 0.5 siempre para cualquier view absoluta, sin importar el valor de τ. El posterior es exactamente el promedio del equilibrio y la view.

Verificación de equivalencia en Python

python
import numpy as np

# Misma Σ, Π, P, q, tau, Omega que antes

# ── Forma 1: estándar ──────────────────────────
tSi   = np.linalg.inv(tau * Sigma)
Oi    = np.linalg.inv(Omega)
mu_1  = np.linalg.inv(tSi + P.T @ Oi @ P) @ (tSi @ Pi + P.T @ Oi @ q)

# ── Forma 2: alternativa (Kalman) ──────────────
K    = tau * Sigma @ P.T @ np.linalg.inv(P @ (tau * Sigma) @ P.T + Omega)
mu_2 = Pi + K @ (q - P @ Pi)

print("Resultados idénticos:", np.allclose(mu_1, mu_2))   # True

τ y Ω no son identificables por separado en la fórmula de BL. Solo importa su ratio. Esto tiene una consecuencia directa: elegir τ no modifica μ_BL si también escalas Ω en la misma proporción.

Demostración formal

K = τΣPᵀ [PτΣPᵀ + Ω]⁻¹

Si τ → c·τ y Ω → c·Ω (escalar ambos por c):
K_nuevo = cτΣPᵀ [PcτΣPᵀ + cΩ]⁻¹ = cτΣPᵀ · c⁻¹ · [PτΣPᵀ + Ω]⁻¹ = K ← sin cambio
Solo el ratio Ω / (τ·PΣPᵀ) determina K — no τ u Ω por separado. Con He-Litterman (Ω = τPΣPᵀ), ese ratio = 1 siempre, dando K = 0.5 para cualquier τ. Subir o bajar τ no cambia nada si Ω se escala junto.

Cuatro enfoques de calibración

He-Litt
1999
He-Litterman — el original
τ = 1/T (inverso del tamaño de muestra). Ω = diag(τ·PΣPᵀ). Por la no-identificabilidad, K = 0.5 para cualquier view absoluta sin importar τ. El posterior siempre cae exactamente entre prior y view.
τ=1/T, Ω=τPΣPᵀ → K=0.5 siempre
Idzor
2005
Idzorek — confianza como porcentaje
Fija τ = 1 y reemplaza la especificación de Ω con un porcentaje de confianza intuitivo p_i ∈ (0,1]. Calibra Ω para que K_i = p_i exactamente. Elimina la degeneración y hace el modelo comunicable al equipo de inversión.
τ=1, Ω_ii=(1−p)/p·(PΣPᵀ)_ii → K_i=p_i
Satch
2000
Satchell-Scowcroft — prior muy preciso
Argumentan que el equilibrio de mercado es muy preciso (τ pequeño, ~0.01). Con Ω separado y fijo, esto da K pequeño: las views tienen poco efecto. Conservador; útil cuando el gestor tiene poca convicción.
τ∈[0.01,0.05], Ω fijo → K pequeño
ML/CV
datos
Máxima verosimilitud / validación cruzada
Estima τ (o el ratio τ/Ω) maximizando la verosimilitud dado el histórico de retornos, o por k-fold cross-validation eligiendo el τ que minimiza el error out-of-sample en Sharpe o tracking error. Riguroso pero necesita T ≥ 100 observaciones.
τ* = argmax_τ L(data | τ)
Recomendación práctica: usa τ = 1 con Idzorek. Elimina la degeneración, las views son comunicables ("tengo 75% de confianza") y K = confianza por construcción. Ver Pestaña 3 para la implementación.

Idzorek (2005) resuelve la degeneración de τ fijando τ = 1 y calibrando Ω desde un porcentaje de confianza intuitivo. K_i = p_i por construcción: si tienes 80% de confianza, el 80% de la sorpresa se incorpora. Al 50% es idéntico a He-Litterman.

La fórmula de calibración

Dado p_i ∈ (0,1] = confianza en la view i

Ω_ii = (1 − p_i)/p_i · (PΣPᵀ)_ii

Verificación: K_i = (PΣPᵀ)_ii / [(PΣPᵀ)_ii + Ω_ii]
= 1 / [1 + (1−p_i)/p_i] = p_i ✓

Nota: p_i = 0.5 → Ω_ii = (PΣPᵀ)_ii = τPΣPᵀ con τ=1 → igual a He-Litterman

Código Python

python
import numpy as np

def idzorek_omega(P, Sigma, confidence):
    """
    Calibra Ω de modo que K_i = confidence[i] para cada view.
    P          : k×n  — matriz de views
    Sigma      : n×n  — covarianzas
    confidence : (k,) — array en (0, 1]
    """
    PSP_diag  = np.diag(P @ Sigma @ P.T)                # varianza de cada view
    omega_diag = PSP_diag * (1 - confidence) / confidence
    return np.diag(omega_diag)

# ── Configuración ──────────────────────────────
tau   = 1.0     # fijo con Idzorek
P     = np.array([[0, 1, 0, 0, 0],
                  [0, 0, 1,-1, 0]])
q     = np.array([0.13, 0.05])   # exceso sobre rf

# Especifica confianza en lugar de Omega
conf       = np.array([0.80, 0.30])
Omega_idz  = idzorek_omega(P, Sigma, conf)

# ── Verificar K = conf ─────────────────────────
K = Sigma @ P.T @ np.linalg.inv(P @ Sigma @ P.T + Omega_idz)
K_diag = np.diag(P @ K.T)
print("K (debe = conf):", K_diag.round(3))   # [0.800, 0.300]

# ── Retornos posteriores BL ────────────────────
tSi   = np.linalg.inv(tau * Sigma)
Oi    = np.linalg.inv(Omega_idz)
M     = np.linalg.inv(tSi + P.T @ Oi @ P)
mu_BL = M @ (tSi @ Pi + P.T @ Oi @ q)

# ── Resultados ─────────────────────────────────
print(f"\n{'Activo':<10}  {'Π total':>9}  {'μ_BL total':>11}  {'Δ':>6}")
for a, pi, mu in zip(activos, Pi + rf, mu_BL + rf):
    print(f"{a:<10}  {pi:>8.2%}   {mu:>10.2%}   {(mu-pi)*100:>+5.1f}pp")
