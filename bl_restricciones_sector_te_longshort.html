Restricciones en Black-Litterman: sector, tracking error y long-short con CVXPY

BL provee μ_BL y Σ_BL como inputs. Las restricciones van en el optimizador, no en la fórmula de BL. El resultado es un QP convexo que CVXPY resuelve en milisegundos incluso con docenas de activos.

min   ½ wᵀΣ_BL w − λ wᵀμ_BL
s.t.  Σ wᵢ = 1                        // totalmente invertido
      wᵢ ≥ 0                         // long-only
      wᵢ ≤ u_i                       // peso máx por activo
      Σ_{i∈S} wᵢ ≤ s_max             // peso máx por sector

python — cvxpy
import cvxpy as cp
import numpy as np

# mu_BL, Sigma_BL : outputs del modelo Black-Litterman
n, lam = 5, 2.5
activos = ['CEMEX','AMX','GFNORTE','WALMEX','BIMBO']

# índices de sectores
ciclico    = [0, 1, 2]   # CEMEX, AMX, GFNORTE
defensivo  = [3, 4]      # WALMEX, BIMBO

w = cp.Variable(n)
obj = cp.Maximize(w @ mu_BL - lam/2 * cp.quad_form(w, Sigma_BL))

constraints = [
    cp.sum(w) == 1,                        # totalmente invertido
    w >= 0,                                # long-only
    w <= 0.45,                             # máx 45% por activo
    cp.sum(w[ciclico]) <= 0.75,            # cíclico ≤ 75%
    cp.sum(w[defensivo]) >= 0.10,          # defensivo ≥ 10%
]

prob = cp.Problem(obj, constraints)
prob.solve(solver=cp.OSQP)

print("Pesos óptimos con restricciones:")
for a, wi in zip(activos, w.value):
    print(f"  {a:<10}  {wi:.1%}")

sig_p = np.sqrt(w.value @ Sigma_BL @ w.value)
sharpe = (w.value @ mu_BL - rf) / sig_p
print(f"\nSharpe: {sharpe:.3f}  |  Vol: {sig_p:.1%}")

Gestores activos comparan su portafolio contra un benchmark. El tracking error (TE) mide la volatilidad de los retornos activos. La restricción de TE obliga a no alejarse demasiado del índice — traduce el "mandato" de inversión en una ecuación.

TE  = √[ (w−w_b)ᵀ Σ_BL (w−w_b) ]  ≤  TE_máx

IR  = Retorno activo / TE  = (w−w_b)ᵀ μ_BL / TE

// La restricción cuadrática convierte el límite de TE en una
// elipse en el espacio de pesos activos. CVXPY la maneja directo.

import cvxpy as cp
import numpy as np

w_bench = np.array([0.15, 0.30, 0.20, 0.25, 0.10])
TE_max  = 0.05     # 5% tracking error anual

w      = cp.Variable(n)
active = w - w_bench   # pesos activos

constraints = [
    cp.sum(w) == 1,
    w >= 0,
    w <= 0.50,
    cp.quad_form(active, Sigma_BL) <= TE_max**2,   # restricción TE
]

obj  = cp.Maximize(w @ mu_BL - lam/2 * cp.quad_form(w, Sigma_BL))
prob = cp.Problem(obj, constraints)
prob.solve(solver=cp.OSQP)

w_opt  = w.value
a_w    = w_opt - w_bench

te  = np.sqrt(a_w @ Sigma_BL @ a_w)
ret_a = a_w @ mu_BL          # retorno activo
ir    = ret_a / te             # information ratio

print(f"Tracking Error:   {te:.2%}  (límite: {TE_max:.2%})")
print(f"Retorno activo:   {ret_a:.2%}")
print(f"Information Ratio: {ir:.3f}")

Un portafolio long-short puede tomar posiciones cortas en activos con views negativas o alta valoración. Esto permite explotar mejor la información de BL — no solo sobreponderar lo que te gusta, sino subponderar lo que no te gusta más allá del cero.

Σ wᵢ = 1                      // net exposure 100% (long-biased)
−short_lím ≤ wᵢ ≤ long_lím   // box constraints
Σ |wᵢ| ≤ gross_lev          // exposición bruta total
β_mkt · w = 0               // optional: market-neutral

import cvxpy as cp
import numpy as np

# Parámetros long-short
short_lim = 0.20    # máximo corto por activo: 20%
long_lim  = 0.60    # máximo largo por activo: 60%
gross_lev = 1.60    # exposición bruta: 160%

w = cp.Variable(n)
constraints = [
    cp.sum(w) == 1,              # net exposure 100%
    w >= -short_lim,             # cortos limitados
    w <= long_lim,               # largos limitados
    cp.norm1(w) <= gross_lev,    # exposición bruta
]

# Opcional: neutralidad de mercado
# betas = np.array([1.2, 0.9, 1.4, 0.7, 0.6])
# constraints.append(betas @ w == 0)

obj  = cp.Maximize(w @ mu_BL - lam/2 * cp.quad_form(w, Sigma_BL))
prob = cp.Problem(obj, constraints)
prob.solve(solver=cp.ECOS)   # ECOS maneja bien L1 constraints

w_opt  = w.value
longs  = float(np.sum(w_opt[w_opt > 0.005]))
shorts = float(np.sum(w_opt[w_opt < -0.005]))
gross  = longs - shorts
sig_p  = float(np.sqrt(w_opt @ Sigma_BL @ w_opt))
sharpe = float((w_opt @ mu_BL - rf) / sig_p)

print(f"Longs:   {longs:+.1%}")
print(f"Shorts:  {shorts:+.1%}")
print(f"Bruta:   {gross:.2f}x")
print(f"Sharpe:  {sharpe:.3f}  (vs long-only)")

print("\nPesos:")
for a, wi in zip(activos, w_opt):
    bar = '█' * int(abs(wi)*50)
    sign = '+' if wi>=0 else '-'
    print(f"  {a:<10} {sign}{abs(wi):.1%} {bar}")
