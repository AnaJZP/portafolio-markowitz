Black-Litterman: intuición, ingredientes, código Python y simulador interactivo

Black y Litterman (1990) lo desarrollaron en Goldman Sachs para resolver los problemas de Markowitz cuando se usa en la práctica. La idea central es bayesiana: se parte de un prior informativo (el equilibrio de mercado) y se actualiza con las views del gestor.

El problema de Markowitz en la práctica
Los retornos esperados μ son muy difíciles de estimar con precisión
Pequeños errores en μ producen pesos extremos (corner solutions)
El portafolio resultante es muy concentrado y poco intuitivo
Cambia radicalmente al actualizar mínimamente los inputs
La solución Black-Litterman
Ancla μ en el equilibrio de mercado (CAPM implícito) como prior
Permite agregar views propias de forma probabilística
Mezcla ambas fuentes ponderando por su incertidumbre
Sin views, el resultado es exactamente el portafolio de mercado
Los 5 ingredientes
Π
Retornos implícitos de equilibrio (prior)
Los retornos que el mercado ya implica vía CAPM, dados los pesos de capitalización de mercado. Son el punto de partida neutral: si no tienes ninguna view, BL te da el portafolio de mercado.
Π = δ · Σ · weq donde δ = (E[rm] − rf) / (weqᵀ Σ weq)
P, q
Views del gestor — la señal diferencial
P (k×n): codifica qué view aplica a qué activos. Una fila por view. View absoluta: un +1 en el activo. View relativa: +1 y −1 (outperformance). q (k×1): el retorno que cada view predice.
View absoluta: P=[0,1,0,…], q=0.13 → "AMX rendirá 13% de exceso"
View relativa: P=[0,0,+1,−1,0], q=0.05 → "GFNORTE supera WALMEX 5%"
Ω
Incertidumbre en las views (k×k diagonal)
Qué tan seguros estamos de cada view. Ω grande → view incierta → el posterior se queda cerca de Π. Ω pequeño → view muy confiable → el posterior converge a q. El método He-Litterman lo calibra automáticamente desde Σ.
He-Litterman: Ω = diag(τ · P Σ Pᵀ)
τ
Escalador de incertidumbre del prior
Cuánta incertidumbre tiene el prior Π. Típico: τ ∈ [0.01, 0.10]. τ → 0: prior muy preciso, las views tienen poco efecto. τ → ∞: el posterior lo determinan solo las views. En la práctica: 1/T donde T es el tamaño de la muestra.
Típico: τ = 0.05 (si T = 20 períodos)
μBL
Retornos posteriores — la media de Bayes
La combinación óptima de Π y q ponderada por sus precisiones. Con estos retornos se hace la optimización de Markowitz normal. La covarianza posterior ΣBL = Σ + M también se actualiza para reflejar la incertidumbre de estimación.
μBL = [(τΣ)⁻¹ + PᵀΩ⁻¹P]⁻¹ · [(τΣ)⁻¹Π + PᵀΩ⁻¹q]

Solo requieres numpy y scipy. Las matrices son las mismas que en el widget anterior. Los datos son sintéticos — en producción reemplaza sigma, corr y cap_mkt con datos reales descargados de yfinance o tu fuente preferida.

python 
import numpy as np
from scipy.optimize import minimize

# ══════════════════════════════════════════════
#  Black-Litterman — implementación desde cero
# ══════════════════════════════════════════════

activos = ['CEMEX', 'AMX', 'GFNORTE', 'WALMEX', 'BIMBO']
n = len(activos)

# 1. Matriz de covarianzas anual (Σ)
sigma = np.array([0.28, 0.20, 0.25, 0.18, 0.16])
corr  = np.array([
    [1.00, 0.50, 0.65, 0.35, 0.30],
    [0.50, 1.00, 0.45, 0.40, 0.35],
    [0.65, 0.45, 1.00, 0.38, 0.32],
    [0.35, 0.40, 0.38, 1.00, 0.55],
    [0.30, 0.35, 0.32, 0.55, 1.00],
])
Sigma = np.outer(sigma, sigma) * corr

# 2. Retornos implícitos de equilibrio Π (exceso sobre rf)
cap_mkt = np.array([0.15, 0.30, 0.20, 0.25, 0.10])
w_eq    = cap_mkt / cap_mkt.sum()

rf, Erm = 0.09, 0.15          # CETES aprox. 9%, IPC esperado 15%
sig2m   = w_eq @ Sigma @ w_eq # varianza del portafolio de mercado
delta   = (Erm - rf) / sig2m  # δ = prima de riesgo / varianza de mercado
Pi      = delta * Sigma @ w_eq # Π = retornos de exceso implícitos

# 3. Views del gestor (también en exceso sobre rf)
#    P : k×n  — qué activos afecta cada view
#    q : k×1  — retorno predicho por cada view
P = np.array([
    [0,  1,  0,  0, 0],   # View 1 (abs): AMX → exceso 13% (22% total)
    [0,  0,  1, -1, 0],   # View 2 (rel): GFNORTE supera WALMEX en 5%
])
q = np.array([0.22 - rf, 0.05])    # [0.13, 0.05]

# 4. Incertidumbre en las views Ω (método He-Litterman)
tau   = 0.05
Omega = np.diag(np.diag(tau * P @ Sigma @ P.T))

# 5. Retornos posteriores Black-Litterman
tSi   = np.linalg.inv(tau * Sigma)       # (τΣ)⁻¹
Oi    = np.linalg.inv(Omega)             # Ω⁻¹
M     = np.linalg.inv(tSi + P.T @ Oi @ P)
mu_BL = M @ (tSi @ Pi + P.T @ Oi @ q)  # retornos de exceso posteriores

Sigma_BL = Sigma + M   # covarianza posterior (incluye incertidumbre de μ)

# 6. Optimización con retornos BL (Máximo Sharpe)
mu_tot = mu_BL + rf    # convertir exceso → retorno total

def neg_sharpe(w):
    return -(w @ mu_tot - rf) / np.sqrt(w @ Sigma_BL @ w)

res = minimize(
    neg_sharpe,
    x0          = np.ones(n) / n,
    method      = 'SLSQP',
    bounds      = [(0, 1)] * n,
    constraints = [{'type': 'eq', 'fun': lambda w: w.sum() - 1}]
)
w_bl = res.x

# 7. Comparación de resultados
print(f"{'Activo':<10}  {'Π total':>9}  {'μ_BL total':>10}")
print("─" * 34)
for a, pi, mu in zip(activos, Pi + rf, mu_tot):
    print(f"{a:<10}  {pi:>8.2%}   {mu:>9.2%}")

print(f"\nPesos óptimos Black-Litterman:")
for a, w in zip(activos, w_bl):
    print(f"  {a:<10} {w:>7.1%}")

print(f"\nSharpe ratio: {-res.fun:.3f}")
